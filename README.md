*  Manually labeled Digisonde tracks dataset

by Berngardt O.I., Ponomarchuk S.N.

* Data description

Totally 132 ionogrames, 52 stations over the world.

Data from Lowell GIRO Data Center (LGDC):
  didbase.gyro.uml.edu

Dates used:
  28/12/2021, 28/09/2022, 28/03/2023, 28/06/2024, 00:00UT

Usual measured parameters per ionogram: 
 Frequency(MHz), Range(km), Amplitude(norm.units), 
 Doppler drift(m/s), Polarization angle(deg.), Azimuth angle(deg.), Zenith angle(deg.)

Data available under CC BY-NC-SA 4.0 license restrictions.
            https://giro.uml.edu/didbase/RulesOfTheRoad.html

* Files description

Data in ./dataset in .npz format

View program in ./progs in Python

Exact list of data used in DATA_USED.txt
